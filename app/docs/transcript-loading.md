# Transcript Loading and Language Selection

This document describes how YCS loads a video transcript, how it picks a caption track, and how the transcript language dropdown maps to state. Reviewers should treat the rules below as the behavior baseline.

---

## Key Components

| File | Purpose |
|------|---------|
| `app/src/source/utils/innertube/transcript.ts` | Track discovery, track selection, and the loading chain (`getTranscriptVideo`) |
| `app/src/source/web-resources/features/transcriptLoader.ts` | Load button, language dropdown, cache save |
| `app/src/source/web-resources/state.ts` | `selectedTranscriptLanguage`, `defaultTranscriptLanguage`, `getEffectiveTranscriptLanguage` |
| `app/src/source/web-resources/appController.ts` | Copies the options-page `transcriptLanguage` into `defaultTranscriptLanguage` |

## Loading Chain

`getTranscriptVideo(signal, { languageCode, autogenerated })` runs these steps in order and returns the first one that yields cues:

1. **Player API, ANDROID client** (no auth header). Returns the caption track list.
2. **Player API, WEB client + SAPISIDHASH** (`racyCheckOk`, `contentCheckOk`). Runs only when step 1 produced no `captions` (e.g. age-restricted videos).
3. **timedtext** on the selected track's `baseUrl` (SAPISIDHASH header). Skipped when no track was selected.
4. **timedtext + `pot`** (`&potc=1&pot=...&c=WEB`). Runs only when step 3 yields no cues and a `pot` token is found on the page.
5. **`get_panel`** (last resort). Runs whenever steps 3-4 yield nothing, including when there are no tracks at all.

Rules:

- `AbortError` is rethrown from both player calls and from `get_panel`; other errors fall through to the next step.
- An empty timedtext body counts as "no cues" and falls through. The ANDROID `baseUrl` can return HTTP 200 with an empty body (e.g. `en0GuyhieQk`), and the `pot` retry can be empty too.
- `youtubei/v1/get_transcript` is intentionally not used: it always returns 400 "Precondition check failed". Do not re-add it.
- `get_panel` must stay last. Its output is lower fidelity (see [get_panel Limitations](#get_panel-limitations)).

## Track Selection

`selectTranscriptTrack(tracks, preferredLanguage, autogenerated, defaultTrack)`:

1. With a preferred language, match tracks by exact code (case-insensitive). If none match, match by primary subtag (`en-US` matches `en`, `en-GB`).
2. Within the matched language, `autogenerated === true` picks the asr track; otherwise the manual track. If the requested kind is missing, the first match is used.
3. No preferred language and `autogenerated === true`: the default track if it is asr, else the first asr track.
4. Otherwise (no language, or no match): the default track. Further fallbacks (first `en*`, first asr, `tracks[0]`) only apply when no default track exists.

### Default Track Resolution

`resolveDefaultTranscriptTrack` tries, in order:

1. Root `defaultCaptionTrackIndex`.
2. The default audio track's `defaultCaptionTrackIndex`.
3. The default audio track's first `captionTrackIndices` entry.
4. `tracks[0]`.

Candidates are matched by `vssId`, so a manual and an asr track with the same language code are not confused.

Step 3 exists for multi-language AI asr videos (e.g. `jt508VjX2H8`, 21 asr tracks). In the ANDROID response these have no root `defaultCaptionTrackIndex` and no per-audio-track `defaultCaptionTrackIndex`; `defaultAudioTrackIndex` points at the original audio (`*.4` id), whose `captionTrackIndices[0]` is the original-language track. Without step 3 the result would be an arbitrary `tracks[0]` language.

## get_panel Language (`hl`)

`get_panel` cannot select a track; it picks the language only from `context.client.hl`:

```
hl = chosen language ?? default track language ?? page HL → navigator.language → 'en'
```

- "Chosen language" is the `languageCode` passed to `getTranscriptVideo` (the effective language; see below).
- Without a chosen language, the default track's language is sent, so the fallback returns the same language timedtext would have.

## Dropdown and State Semantics

State fields:

- `selectedTranscriptLanguage`: the language picked in the dropdown this session. Not persisted.
- `defaultTranscriptLanguage`: the options-page default (`transcriptLanguage`, trimmed; empty = unset).
- `getEffectiveTranscriptLanguage` = `selectedTranscriptLanguage ?? defaultTranscriptLanguage`. `undefined` means the YouTube default track.

Behavior:

- **Load button** loads the effective language with `autogenerated` unset (manual preferred within the language).
- **Language item** sets the session pick to that track's code and loads it, passing `autogenerated` = the item's asr flag.
- **"Default (YouTube / options)" item** clears the session pick and loads, so the effective language falls back to the options default, else the YouTube default track.
- **Active highlight** follows the session pick, not the effective language: "Default" is active when there is no pick; otherwise the item whose code equals the pick. Exactly one language should be active at a time.

### Known Limitation

The session pick stores only the language code, not the track kind. When a language has both a manual and an auto track:

- Both items highlight after either one is picked.
- Load after picking the auto item loads the manual track (Load passes no `autogenerated`).

A follow-up PR is fixing this. Until then, do not treat these two symptoms as new regressions.

## get_panel Limitations

Verified in a real browser (2026-10-09):

- Endpoint `POST /youtubei/v1/get_panel` with `panelId: 'PAmodern_transcript_view'`; without `panelId` it returns 400.
- `params` = base64 of protobuf `field149 { 1: videoId, 3: 1 }`. No auth header, cookies, or visitor id are required.
- Language follows `hl` only. AI-generated multi-language asr tracks cannot be selected; the original language is returned.
- No pagination: one section per chapter. All sections are flattened; chapter-title items are skipped.
- Segments are paragraph-merged with second precision and carry no duration (derived from the next segment's start; the last one uses the playing video's length, else 0). `jt508VjX2H8` yields 603 cues vs 2093 from timedtext.
- No transcript: HTTP 200 without a `content` key, treated as no result.
